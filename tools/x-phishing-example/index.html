Do not enter your real X username or password.

I created this application after multiple mutual followers on X lost access to their accounts due to sophisticated phishing schemes.

I have been targeted for this hack in two different ways:

  • User was asked to vote for a user to be on a podcast.
  • User was told that their account was inadvertently reported and that they needed to address it.
  1. I A user receives a message on X, directing them to a page where they are prompted to log in.
  2. II The user attempts to log in, inadvertently sending their login credentials to a hacker.
  3. III The hacker uses the credentials to access the account and changes the email / password.

The form below works exactly like the hack. Therefore, it is NOT necessary to enter your real username and password. No values are stored or sent. They are only displayed so that you can see how the hack works. Had this been a real phishing site, the form below would be sent to a hacker which would provide them with your login details.

Type a fake name like demo_user and a fake password like not-my-real-password.
