SM API URL Generator

Creates a URL for SAP Ariba Support Engineers to use with an internal API. Additional requirements are on this Wiki page (internal SAP Ariba network only).

SM Advanced View URL Generator

Creates a URL to open Advanced View for SLP projects, including workspaces that have not yet indexed. You must already be logged into the customer site, or the URL will route to the login screen.

Generated URL

Instructions

  1. Select either SM API or Advanced View.
  2. Copy / paste the customer's realm name into the Realm Name field and select the appropriate Data Center.
  3. Enter the SM Vendor ID of the supplier or the Workspace ID of the project based on your selection.
  4. Click Generate URL, then Copy URL to place it on your clipboard.

Usage

This application is optimized for use by SAP Ariba Support Engineers. Feel free to download the source code and update, change, or host the application on your Internal GitHub page. No credit is necessary.
